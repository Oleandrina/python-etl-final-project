# Итоговый проект по Python: ETL-процесс обработки данных

## Описание проекта

Проект представляет собой ETL-процесс для получения и обработки статистики попыток решения задач студентами онлайн-университета.

Программа получает данные через API, проверяет их корректность, преобразует и загружает в локальную базу данных PostgreSQL.

Дополнительно реализованы выгрузка агрегированной статистики в Google Sheets и отправка email-уведомлений.

## Используемые технологии

- Python
- Jupyter Notebook
- requests — получение данных из API
- PostgreSQL и psycopg2 — хранение данных
- logging — журналирование работы программы
- python-dotenv — загрузка переменных окружения из файла .env
- gspread — работа с Google Sheets
- smtplib, ssl, email — отправка email-уведомлений

## Основные этапы работы

1. Получение данных из API ITResume.
2. Преобразование и валидация полученных записей.
3. Загрузка корректных записей в PostgreSQL.
4. Логирование этапов обработки и возникающих ошибок.
5. Агрегация ежедневной статистики и выгрузка в Google Sheets.
6. Отправка email-уведомлений.

## Установка и запуск проекта

### 1. Подготовка окружения

Для запуска проекта необходимы Python, JupyterLab, PostgreSQL и доступ к API ITResume.

Установите необходимые библиотеки Python:

```bash
pip install requests psycopg2-binary python-dotenv gspread certifi
```

### 2. Настройка переменных окружения

Создайте в папке проекта файл `.env`:

```dotenv
ITRESUME_CLIENT_KEY=ваш_ключ_API
POSTGRES_PASSWORD=ваш_пароль_PostgreSQL
```

Укажите собственные значения ключа API и пароля PostgreSQL.

Файл `.env` содержит конфиденциальные данные и не должен публиковаться на GitHub.

### 3. Подготовка PostgreSQL

Установите и запустите PostgreSQL. Создайте локальную базу данных `final_project` и настройте подключение к ней.

Таблица `attempts` создаётся автоматически при выполнении ноутбука, если она отсутствует.

### 4. Запуск проекта

Откройте `final_project.ipynb` в JupyterLab и выполняйте ячейки последовательно, начиная с первой.

Период выгрузки данных задаётся переменными `START_DATE` и `END_DATE`.

### 5. Дополнительные возможности

Для работы с Google Sheets необходимы учётные данные сервисного аккаунта Google и доступ к таблице.

Для отправки email-уведомлений требуется почтовый аккаунт с паролем приложения.

Эти конфиденциальные настройки пользователь подготавливает самостоятельно и не публикует в репозитории.
